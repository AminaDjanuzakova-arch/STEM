# 🧬 BIO QUIZ — Путешествие в мир биологии

Интерактивный образовательный квиз по биологии для школьников.  
Современная игровая викторина: очки, серии, комбо, жизни, подсказки, достижения и таблица рекордов.

## Возможности

- 120 вопросов по 10 темам биологии
- 4 уровня сложности: Легко / Средне / Сложно / Эксперт
- Выбор категории или режим «Все темы»
- 10 типов вопросов (обычный, правда/ложь, загадка, «кто я?» и др.)
- Таймер 20 секунд, жизни, подсказки (50/50, подсказка, +10 сек)
- Система очков, серии и COMBO x2 / x3
- Биологический факт после каждого ответа
- Профиль, достижения, таблица рекордов (localStorage)
- Настройки: звук, тема, таймер, жизни, анимации
- Адаптивный интерфейс (телефон, планшет, десктоп)

## Запуск

```bash
npm install
npm run dev
```

Открой в браузере адрес, который покажет Vite (по умолчанию `http://localhost:4321`).

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Структура

```
index.html
vite.config.js
src/
  main.js        — логика игры и экраны
  questions.js   — база вопросов
  audio.js       — звуки через Web Audio API
  storage.js     — localStorage
  style.css      — стили
public/
  favicon.svg
```

## Технологии

HTML · CSS · JavaScript · Vite  

Без серверной части и внешних платных сервисов. Всё работает локально в браузере.
