# 🧬 BIO QUIZ — квиз по биологии для 4 класса

Два отдельных сайта в одном проекте:

| Кто | Адрес |
|-----|--------|
| **Ученики** | главная страница `/` |
| **Учитель** | страница `/teacher.html` |

Ученикам **не нужна** установка и регистрация — только ссылка в браузере.

---

## Как открыть игру ученикам

1. Откройте **публичную ссылку** на сайт учеников (её вы получите после публикации).
2. Отправьте ссылку детям в чат / мессенджер / на доску.
3. На **своём** компьютере откройте страницу учителя `/teacher.html`.
4. Войдите с PIN (по умолчанию `1234`).
5. Нажмите **«Создать новую сессию»** — появится большой код и QR.
6. Покажите код/QR классу. Дети вводят **имя** и **код** и играют.

> Не отправляйте детям ссылку на `/teacher.html` — это только для вас.

---

## Как обновить игру после изменений

Если проект уже опубликован через Cursor:

1. Попросите агента внести правки (или измените код).
2. После сохранения изменений агент может **опубликовать обновление** снова.
3. Та же ссылка продолжит работать — обновите страницу в браузере (`F5`).

Если публикуете через **Vercel** (сайт vercel.com):

1. Зайдите на [vercel.com](https://vercel.com) и войдите.
2. Откройте свой проект BIO QUIZ.
3. Нажмите **Redeploy** (или просто запушьте изменения в репозиторий — Vercel обновит сам).

Локальная проверка у себя на компьютере:

```bash
npm install
npm run build
npm run preview
```

## Что внутри (для справки)

- HTML + CSS + JavaScript, сборка Vite
- Картинки и шрифты лежат в папке `public/`
- Секретов в коде нет (Supabase подключается только если вы сами добавите ключи)
- Прогресс незавершённой игры сохраняется в браузере ученика

Файлы публикации: `vercel.json` (сборка в папку `dist`).
